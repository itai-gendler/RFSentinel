# Custom theme

A theme the user made, imported or duplicated: an accent colour, a light, dark or black base, a font, a banner, a header and a map marker.

## Information kept

- **Name** — Distinct user-facing name.
- **Appearance** — Saved appearance choices.
- **Font** — Selected font or imported font asset.
- **Banner** — Optional imported image.
- **Header** — User-defined header content.
- **Marker** — User-selected map marker.
